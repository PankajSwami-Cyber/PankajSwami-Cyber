# Incident Handler's Journal

## Overview

This repository documents my cybersecurity learning journey and practical incident response exercises.

## Topics Covered

* Incident investigation using the 5 W's
* The NIST Incident Response Lifecycle
* Wireshark packet capture and network traffic analysis
* VirusTotal threat indicator triage
* Incident documentation and response recommendations

## Learning Objectives

My goal is to improve my skills in identifying suspicious activity, analyzing evidence, documenting findings, and understanding incident response procedures.

**Note:** Any scenarios identified as simulated are practice examples, not verified real-world security incidents.
