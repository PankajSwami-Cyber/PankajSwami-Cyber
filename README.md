## 🎯 Skills Covered

The Google Cybersecurity Professional Certificate covers several important areas of cybersecurity.

### 1. Foundations of Cybersecurity
- Introduction to cybersecurity.
- Security principles and concepts.
- Common cyber threats and vulnerabilities.
- Security policies and best practices.
- CIA Triad (Confidentiality, Integrity, Availability).

### 2. Manage Security Risks
- Risk assessment and management.
- Security controls.
- NIST Cybersecurity Framework.
- Security compliance.
- Vulnerability management.

### 3. Networks and Network Security
- Network fundamentals.
- TCP/IP and networking protocols.
- Network architecture.
- Network traffic analysis.
- Firewalls and network security.

### 4. Linux and SQL
- Linux command-line fundamentals.
- File and directory management.
- Linux permissions.
- SQL queries and database fundamentals.
- Security-related data analysis.

### 5. Assets, Threats, and Vulnerabilities
- Asset identification and management.
- Threat intelligence.
- Vulnerability assessment.
- Attack vectors.
- Common security vulnerabilities.

### 6. Detection and Response
- Security Information and Event Management (SIEM).
- Log analysis.
- Security monitoring.
- Incident detection.
- Incident response procedures.

### 7. Python for Cybersecurity
- Python programming fundamentals.
- Automating repetitive security tasks.
- Working with files.
- Using Python to analyze security-related data.

### 8. Prepare for Cybersecurity Jobs
- Security analyst responsibilities.
- Incident response workflows.
- Security documentation.
- Professional development.
- Cybersecurity career preparation.
