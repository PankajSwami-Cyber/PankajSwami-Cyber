# Pyramid of Pain – VirusTotal Malware Analysis

## Overview

This project documents a cybersecurity investigation involving a suspicious spreadsheet attachment that resulted in the execution of a malicious payload.

The investigation used VirusTotal to analyze a SHA256 file hash and identify additional indicators of compromise (IoCs). The findings were then mapped to the Pyramid of Pain framework.

## Objectives

* Determine whether the file hash was malicious.
* Analyze VirusTotal detection results.
* Identify additional indicators of compromise.
* Categorize IoCs using the Pyramid of Pain.
* Document the investigation in a clear SOC analyst workflow.

## Investigation Method

The analysis reviewed:

* VirusTotal Detection information
* VirusTotal Details information
* VirusTotal Relations
* VirusTotal Behavior and sandbox information

## Key Conclusion

The investigated file was assessed as malicious based on the available VirusTotal detection information and associated threat intelligence.

The investigation demonstrated how a single file hash can be used to identify additional IoCs and how those IoCs can be organized using the Pyramid of Pain.
