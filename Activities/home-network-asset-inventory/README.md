# 🏠 Home Network Asset Inventory

## 📌 Overview

This project demonstrates the fundamentals of **asset management** by creating an inventory of devices connected to a home office network. The objective is to identify network assets, document their characteristics, and classify them based on their sensitivity to support better security and risk management.

Asset management is a foundational cybersecurity practice because organizations must know what assets they own before they can effectively protect them.

---

## 🎯 Objectives

- Identify devices connected to a home network.
- Create an inventory of network assets.
- Record important asset attributes such as owner, location, and network access.
- Classify assets based on sensitivity.
- Understand the role of asset inventories in reducing security risks.

---

## 🛠️ Project Tasks

The following assets were identified and documented:

- Network Router
- Desktop Computer
- Guest Smartphone

Each asset was evaluated using the following attributes:

- Network Access
- Owner
- Location
- Notes
- Sensitivity Level
- Access Designation

The completed inventory identifies the network router, desktop, and guest smartphone along with their ownership, location, notes, and assigned sensitivity levels.

---

## 🔒 Asset Classification Summary

| Asset | Sensitivity | Reason |
|--------|-------------|--------|
| Network Router | Confidential | Provides connectivity for all devices on the home network. |
| Desktop Computer | Restricted | Contains private information such as personal photos. |
| Guest Smartphone | Confidential | Connects to the home network and should have limited access. |

This summary reflects the classifications documented in the inventory.
