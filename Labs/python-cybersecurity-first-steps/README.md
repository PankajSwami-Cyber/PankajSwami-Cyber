# Python Basics for Security Analysts

A beginner-friendly Jupyter Notebook demonstrating a few Python fundamentals relevant to a cybersecurity learning journey.

## What this project covers

- The difference between Markdown and code cells in a Jupyter Notebook
- Writing Python comments with `#`
- Displaying strings with `print()`
- Combining multiple `print()` statements in one cell

## Project structure

```text
python-cybersecurity-first-steps/
├── README.md
├── .gitignore
└── notebooks/
    └── python_basics_for_security_analysts.ipynb
```

## Open the notebook

**Option 1 — Google Colab**

1. Open [Google Colab](https://colab.research.google.com/).
2. Select **File → Upload notebook**.
3. Choose `notebooks/python_basics_for_security_analysts.ipynb`.
4. Run the cells from top to bottom using **Shift + Enter** or the Run button.

**Option 2 — Jupyter Notebook / JupyterLab**

1. Install Python if it is not already installed.
2. Install Jupyter with `python -m pip install notebook` (or use an existing JupyterLab installation).
3. From this project folder, run `jupyter notebook`.
4. Open the notebook in the `notebooks/` folder and run the cells.

No third-party Python packages are required by the notebook itself.

## Learning outcomes

After completing the notebook, a learner should be able to explain how Markdown and code cells differ, add comments to document code, and use `print()` to display strings.
